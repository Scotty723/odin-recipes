
# Odin Recipes

This is my first HTML project for The Odin Project.

The goal is to build a basic recipe website with a homepage
that links to different recipes.

By completing this project, I will practice:

- Writing HTML boilerplate
- Using headings and paragraphs
- Creating links between pages
- Adding images and alt text
- Creating ordered and unordered lists
- Using Git and GitHub to track my progress
